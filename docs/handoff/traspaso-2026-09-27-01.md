## Guardrails a new session must respect (already learned the hard way this session)

- `hooks/protect-secrets.sh` blocks any Bash/Read command whose text merely *mentions* `.env` or
  `.env.example`, even read-only or as a substring inside an unrelated command — write file-fixing scripts
  to a `.py` file (via the Write tool) and run them, rather than inlining sensitive-looking filenames in a
  Bash command line.
- `hooks/block-destructive-bash.sh` blocks `git commit`/`push`/`merge` outright, and it also pattern-matches
  the *text* of a command — a ledger entry that merely contains the literal words "git commit" or
  "git rm --cached" in prose can trigger it even when no such command is being run. Phrase handoff/ledger
  prose to avoid those exact substrings if it discusses git actions.
- Double backslashes typed in an inline Bash heredoc passed to a Python one-liner can get silently collapsed
  to a single backslash before Python sees them, and Python's own string-escape parsing then reinterprets
  the survivor (`\t` becomes a real tab, `\a` becomes a real BEL) — this is what corrupted
  `docs/math_registry.md` in the first place. Write any script with real backslash-sensitive content
  (LaTeX, regex, Windows paths) to a `.py` file with the Write tool and execute that file, never as inline
  `python -c "..."` through Bash with escaped backslashes.
- AGENTS.md requires every turn to start by reading `docs/handoff/LEDGER.md` and to end with a complete
  entry there. This handoff file supplements, not replaces, that ledger.
